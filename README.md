# Навчальні картки: CSS Box Model та позиціювання

## Мета проєкту
Проєкт створено для практичного засвоєння блокової моделі CSS (Box Model), керування внутрішніми й зовнішніми відступами, рамками, переповненням контенту та базовим позиціюванням елементів без використання складних систем розкладки.

## Використані CSS-властивості
* **`box-sizing: border-box`** — налаштовано глобально через `*, *::before, *::after`, щоб `padding` та `border` входили в задану ширину блоків.
* **`padding`** — у першій картці використано збільшений верхній відступ (`48px`), щоб зарезервувати місце для позначки; у другій картці застосовано компактніші відступи (`16px 20px`).
* **`border`** — застосовано суцільну рамку `2px solid` для першої картки та пунктирну `5px dashed` для другої.
* **`margin`** — використано `margin: 24px auto` та `margin: 40px auto` для вертикального розділення карток і їх центрування по горизонталі.
* **`position: relative` та `position: absolute`** — задано контекст позиціювання для першої картки та розміщено позначку «Нове» у верхньому правому куті за допомогою логічних властивостей `inset-block-start` та `inset-inline-end`.
* **`overflow: hidden` та `overflow-wrap: break-word`** — запобігають виходу тексту або елементів за межі блоків та появі горизонтального скролу.

## Результат перевірки в DevTools
Розміри двох карток і позиціювання позначки перевірено в DevTools (вкладка Elements -> Computed / Box Model). Загальна ширина обох карток на десктопі становить рівно `480px` (включно з рамками та внутрішніми відступами завдяки `border-box`), на вузькій ширині позначка не перекриває заголовок, а горизонтальний скрол сторінки відсутній.
