Нове

Основи CSS Box Model

У цій картці застосовано великий верхній внутрішній відступ (padding-top), щоб зарезервувати місце для позначки «Нове». Навіть на вузькому екрані позначка не перекриває заголовок.

Робота з рамками та переповненням

Ця картка має товщу рамку (border), менші внутрішні відступи та більший зовнішній відступ (margin). Властивість overflow-wrap гарантує, що довгі слова або посилання, наприклад https://mozilla.org, не вийдуть за межі блоку.
